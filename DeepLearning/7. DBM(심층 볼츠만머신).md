# DBM(심층 볼츠만 머신): RBM과 비교하는 쉬운 해설

## 1. DBM이란?
DBM(Deep Boltzmann Machine)은 **여러 은닉층을 가진 심층 확률모델**이다. 인접한 층 사이의 연결이 양방향으로 작동하며, 여러 수준의 잠재 특징과 그 관계를 함께 표현한다.

> 한 문장: RBM이 한 단계에서 통계적 패턴을 학습한다면, DBM은 여러 층에서 패턴들의 복잡한 관계를 학습한다.

## 2. 사과 사진으로 설명
사과 사진을 입력했을 때 다음과 같은 표현이 가능하다고 가정하자.

```text
은닉층 3 (선택) : 여러 부분의 복합적 관계
         ↕
은닉층 2         : 곡선·색상 등 패턴들의 조합
         ↕
은닉층 1         : 선·경계·색상 변화 등 기초 패턴
         ↕
가시층           : 사과 사진의 픽셀값
```

**주의:** 위 계층은 이해를 돕는 예시다. 실제 DBM이 반드시 '선 → 둥근 형태 → 사과' 순서로 학습하거나 '사과'라는 의미를 아는 것은 아니다.

## 3. RBM과 DBM의 차이
| 구분 | RBM | DBM |
|---|---|---|
| 은닉층 | 한 개 | 여러 개 |
| 구조 | 가시층 ↔ 은닉층 | 가시층 ↔ 은닉층 1 ↔ 은닉층 2… |
| 표현 | 한 단계의 잠재 통계 패턴 | 여러 층의 복합적 잠재 관계 |
| 학습 | 상대적으로 단순 | 추론·학습이 더 복잡 |
| 계산 비용 | 비교적 낮음 | 일반적으로 높음 |
| 교육적 활용 | CD와 확률적 패턴 학습 이해 | 심층 에너지 기반 모델 연구 |

DBM은 RBM 여러 개를 단순히 쌓은 것과 같지 않다. **모든 층이 하나의 확률모델로 상호작용**한다.

## 4. DBM은 어떻게 학습하는가?
1. 실제 사과 사진이 주어졌을 때 여러 은닉층의 활성화 관계를 **근사 추론**한다.
2. 모델이 나타내는 확률분포의 통계적 관계를 **샘플링 등으로 근사**한다.
3. 두 관계의 차이를 반영해 모델 전체의 가중치를 조정한다.

RBM은 대조발산(CD)을 이용해 비교적 간단히 학습할 수 있지만, DBM은 여러 은닉층이 서로 영향을 주므로 학습과 추론이 어렵다. 역사적으로 층별 사전학습으로 초기 가중치를 얻고 전체 모델을 학습시키는 접근도 활용했다.

## 5. 어느 때 RBM, 어느 때 DBM을 사용하는가?
- **RBM:** 간단한 확률적 특징 학습 실험, 대조발산 원리 교육, 소규모 에너지 기반 모델 연구
- **DBM:** 여러 잠재층의 복잡한 확률적 관계 연구, 심층 에너지 기반 모델의 추론·학습 연구
- **일반적인 과일 사진 분류:** 보통 CNN, Vision Transformer 같은 현대적 분류 모델을 먼저 고려

DBM이 더 깊다고 해서 무조건 정확도가 높지는 않다. 학습 복잡도와 데이터 특성을 함께 고려해야 한다.

## 6. DBM과 DBN 구별
- **DBM(Deep Boltzmann Machine):** 인접한 층 사이에 양방향 확률적 연결이 있는 심층 모델
- **DBN(Deep Belief Network):** 상위 층의 양방향 연결과 하위 층의 방향성 있는 생성 연결을 포함하는 모델

두 모델은 구조와 학습 방식이 다르므로 혼동하지 않는다.

## 7. 핵심 정리
**RBM은 한 은닉층으로 패턴을 학습하고, DBM은 여러 은닉층이 상호작용하며 복잡한 통계적 관계를 학습한다. DBM은 표현력이 풍부할 수 있지만 학습과 추론 비용도 크다.**
