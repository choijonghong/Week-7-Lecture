# 「Gradient-Based Learning Applied to Document Recognition」

## Ⅰ. Introduction(서론) — 10줄 요약

1. **연구 배경:** 컴퓨터가 손글씨와 문서를 정확하게 인식하려면 복잡한 패턴 인식 기술이 필요하다.
2. **기존 방식의 한계:** 사람이 글자의 특징을 직접 설계하고 인식 규칙을 만드는 데 많은 노력이 필요했다.
3. **새로운 접근:** 사람이 규칙을 일일이 만드는 대신 컴퓨터가 데이터를 통해 인식 방법을 학습하도록 한다.
4. **경사 기반 학습:** 인식 오류를 줄이는 방향으로 신경망의 가중치를 반복적으로 수정한다.
5. **역전파 알고리즘:** 최종 결과에서 발생한 오류를 앞쪽 계층으로 전달하여 각 계층을 학습시킨다.
6. **CNN의 활용:** 합성곱 신경망은 글자의 선, 곡선, 형태 등 중요한 특징을 자동으로 추출한다.
7. **가중치 공유:** 동일한 필터를 이미지 여러 위치에 적용하여 학습할 매개변수를 줄인다.
8. **문서 인식의 어려움:** 여러 글자가 붙어 있으면 글자를 나누는 작업과 인식하는 작업을 분리하기 어렵다.
9. **GTN의 필요성:** 문자 분할, 문자 인식, 문맥 분석 등을 그래프 변환기로 연결하여 전체 시스템을 학습시킨다.
10. **연구의 목표:** CNN과 GTN을 활용하여 손글씨 숫자, 단어, 은행 수표 등을 정확하고 효율적으로 인식하는 방법을 제시한다.

## 핵심 결론

서론에서는 문서 인식의 복잡한 문제를 사람이 만든 규칙에만 의존하지 않고, **경사 기반 학습을 통해 자동으로 해결하는 방향**을 제시한다. CNN은 특징 추출을 학습하고, GTN은 여러 인식 단계를 연결하여 전체 시스템을 최적화한다.

## 서론의 세부 구성: A~E절 상세 설명

> 아래 내용은 논문 Ⅰ장(Introduction)의 A~E절을 원문 흐름에 따라 쉽게 풀어 쓴 **해설형 요약**입니다. 수치 예시는 개념 이해를 위한 가상 사례입니다.

### A. Learning from Data — 데이터로부터 학습

**핵심:** 사람이 문자 인식 규칙을 모두 작성하는 대신, 입력 이미지와 정답이 있는 **학습 데이터**를 이용하여 모델의 매개변수(가중치)를 조정한다.

- 학습 모델은 입력 이미지 `Z`를 받아 숫자별 점수나 예측 결과를 만든다.
- 정답과 예측 사이의 차이를 **손실 함수(Loss Function)**로 측정한다.
- 학습 데이터에서의 오류가 작아도 처음 보는 데이터에서 잘못 읽을 수 있으므로 **훈련 성능과 시험 성능**을 구분해야 한다.
- 모델이 지나치게 복잡하면 훈련 자료만 외우는 **과적합**이 발생할 수 있다. 논문은 일반화 성능, 모델 용량, 정규화의 관계를 논의한다.

**쉬운 예:** 손글씨 숫자 `3`을 1만 장 보여 주며 정답을 알려 준다. 모델은 여러 사람이 쓴 `3`의 공통 특징을 배우고, 처음 보는 사람의 `3`도 맞혀야 한다.

### B. Gradient-Based Learning — 경사 기반 학습

**핵심:** 오류를 줄이는 방향을 **기울기(경사, Gradient)**로 계산하고 가중치를 조금씩 수정한다.

- 가중치를 바꾸면 손실이 얼마나 증가하거나 감소하는지 미분으로 파악한다.
- **경사하강법(Gradient Descent)**은 손실이 감소하는 방향으로 가중치를 갱신한다.
- 논문은 전체 학습 자료의 평균 경사뿐 아니라, 하나의 학습 사례를 이용해 자주 갱신하는 **확률적 경사하강법(SGD)**도 설명한다.

**쉬운 예:** `8`을 `3`으로 잘못 인식했다면, 오류가 작아지는 방향으로 필터의 숫자들을 조금 바꾼다. 이런 수정을 반복해 `8`과 `3`을 더 잘 구별한다.

### C. Gradient Back-Propagation — 경사 역전파

**핵심:** 여러 층으로 이루어진 신경망에서 최종 오류의 경사를 **출력층에서 입력층 방향으로 효율적으로 전달**한다.

- 출력 결과만 보고는 앞쪽 필터를 어떻게 수정해야 하는지 곧바로 알기 어렵다.
- 역전파는 **연쇄법칙(Chain Rule)**을 이용해 각 계층의 가중치가 최종 오류에 미치는 영향을 계산한다.
- 논문은 역전파의 발전 과정과 다층 신경망 학습에서의 중요성을 설명한다.

**쉬운 예:** 숫자 `5`를 `6`으로 잘못 읽었다면, 마지막 분류층뿐 아니라 그 앞에서 곡선과 선을 검출한 필터들까지 오류 정보를 전달하여 수정한다.

**주의:** 경사하강법은 **어느 방향으로 가중치를 수정할지 정하는 방법**이고, 역전파는 **그 수정에 필요한 경사를 계산하는 방법**이다.

### D. Learning in Real Handwriting Recognition Systems — 실제 손글씨 인식 시스템에서의 학습

**핵심:** 숫자 한 개를 분류하는 것과, 여러 숫자가 붙은 **실제 문서 전체를 읽는 것**은 다르다.

- 독립된 숫자 인식에는 CNN이 좋은 성능을 보이지만, 실제 문서에서는 **문자 분할(Segmentation)**이 어렵다.
- **과잉 분할(Over-Segmentation)** 방식은 가능한 절단 지점을 여러 개 만든 뒤 가장 좋은 조합을 선택한다.
- 문제는 잘못 잘린 조각에 일관된 정답 라벨을 붙이기 어렵다는 점이다.
- 논문은 전체 문자열 단위로 학습하는 접근과, 인식기를 이미지 위로 이동시켜 문자를 찾는 **분할 없는 접근**을 소개한다.

**쉬운 예:** 손글씨 `12`에서 `1`과 `2`가 붙어 있으면 어디서 잘라야 할지 불분명하다. 여러 분할 후보를 보존하거나 이미지를 훑으며 문자 후보를 찾은 뒤, 전체 문자열로 가장 타당한 해석을 선택한다.

### E. Globally Trainable Systems — 전체 학습이 가능한 시스템

**핵심:** 문서 인식 시스템의 각 모듈을 따로 최적화하는 대신 **최종 문서 인식 오류를 기준으로 전체 시스템을 공동 학습**한다.

- 실제 시스템은 보통 **영역 검출 → 문자 분할 → 문자 인식 → 문맥에 따른 최종 선택**으로 구성된다.
- 기존에는 각 모듈을 별도로 조정하고, 연결한 뒤 다시 수동으로 성능을 맞추는 경우가 많았다.
- 논문은 여러 해석 후보와 점수를 **그래프(Graph)**로 표현하고, 그래프를 입력받아 다른 그래프로 바꾸는 **Graph Transformer**를 연결한다.
- 이렇게 연결된 시스템이 **GTN(Graph Transformer Networks)**이다.
- 미분 가능한 모듈을 연결하면 **전체 손실 함수**를 기준으로 학습 가능한 매개변수의 경사를 계산하고 수정할 수 있다.

**쉬운 예:** 은행 수표의 금액 `1200`을 `1700`으로 읽었다면, 마지막 결과만 고치는 것이 아니라 앞쪽 문자 인식기의 가중치와 학습 가능한 점수 계산 요소까지 함께 개선한다.

|---|---|---|---|
| A. Learning from Data | 무엇을 보고 배우는가? | 학습 데이터, 일반화, 과적합 | 다양한 필체를 보고 익히기 |
| B. Gradient-Based Learning | 어떻게 오류를 줄이는가? | 경사하강법, SGD | 틀린 방향을 조금씩 바로잡기 |

| D. Learning in Real Handwriting Recognition Systems | 실제 붙어 있는 글자는 어떻게 읽는가? | 문자 분할, 과잉 분할, 분할 없는 인식 | 붙어 쓴 `12`를 구별하기 |
