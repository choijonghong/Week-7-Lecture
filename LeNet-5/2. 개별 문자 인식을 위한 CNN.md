# Ⅱ. 개별 문자 인식을 위한 합성곱 신경망(CNN)

**원문:** *Convolutional Neural Networks for Isolated Character Recognition*  
**출처:** LeCun 외(1998), *Gradient-Based Learning Applied to Document Recognition*

## 핵심 내용 20줄 요약

1. **연구 목적:** 손글씨 숫자와 문자를 정확하게 인식하기 위한 합성곱 신경망(CNN)의 원리와 구조를 설명한다.
2. **기존 신경망의 한계:** 완전연결 신경망은 이미지의 모든 픽셀을 연결하므로 학습할 가중치가 많아지고 위치 변화에 민감하다.
3. **CNN의 기본 원리:** 이미지의 공간적 구조를 활용하여 중요한 특징을 자동으로 추출하고 학습한다.
4. **국소 수용 영역(Local Receptive Field):** 이미지 전체가 아닌 작은 영역을 분석하여 선, 모서리, 곡선 등의 특징을 찾는다.
5. **가중치 공유(Weight Sharing):** 동일한 필터를 이미지의 여러 위치에 적용하여 학습 매개변수를 줄인다.
6. **특징맵(Feature Map):** 하나의 필터가 이미지 전체에서 특정 특징을 찾아낸 결과를 나타낸다.
7. **합성곱층(Convolutional Layer):** 여러 필터를 사용하여 다양한 특징맵을 생성하고 문자 형태를 분석한다.
8. **서브샘플링층(Subsampling Layer):** 특징맵의 크기를 줄여 글자의 위치 이동과 형태 변형에 대한 민감도를 낮춘다.
9. **계층적 특징 학습:** 앞쪽 계층에서는 단순한 선과 곡선을, 뒤쪽 계층에서는 복잡한 문자 형태를 학습한다.
10. **LeNet-5 구조:** 합성곱층과 서브샘플링층 등을 결합한 7개 학습 계층의 대표적인 CNN 모델을 제시한다.
11. **입력층:** 손글씨 숫자를 32×32픽셀 이미지로 입력하여 신경망에 전달한다.
12. **C1 계층:** 5×5 필터를 이용해 28×28 크기의 특징맵 6개를 생성한다.
13. **S2 계층:** 2×2 영역의 평균을 이용하여 14×14 크기의 특징맵 6개로 축소한다.
14. **C3 계층:** 앞 계층의 특징맵을 부분적으로 연결하여 10×10 크기의 특징맵 16개를 생성한다.
15. **S4 계층:** 특징맵을 다시 축소하여 5×5 크기의 특징맵 16개를 생성한다.
16. **C5 계층:** 120개의 뉴런을 통해 앞 계층에서 추출한 특징들을 종합한다.
17. **F6 계층:** 84개의 뉴런을 사용하여 문자를 구별하기 위한 최종 특징 표현을 생성한다.
18. **출력층:** RBF(Radial Basis Function)를 이용해 입력 특징과 문자별 기준 벡터 사이의 거리를 계산한다.
19. **손실함수와 역전파:** 올바른 문자의 벌점을 낮추고 잘못된 문자의 벌점을 높이는 학습 기준을 사용하며, 역전파로 가중치를 수정한다.
20. **연구의 핵심:** CNN은 국소 수용 영역, 가중치 공유, 서브샘플링을 결합하여 손글씨 인식에 필요한 특징을 효율적으로 학습한다.

## 쉬운 예: 손글씨 숫자 '8' 인식

손글씨 숫자 **'8'**을 입력하면 C1에서 짧은 선과 곡선을 찾고, C3에서 이를 결합해 복잡한 형태를 파악합니다. S2와 S4는 특징 정보를 압축하고, C5와 F6는 전체 숫자의 특징을 종합합니다. 마지막으로 RBF 출력층에서 숫자 0~9의 기준 패턴과 비교하여 '8'을 선택합니다.
