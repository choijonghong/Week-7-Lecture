# Ⅳ. 다중 모듈 시스템과 그래프 변환 네트워크(GTN)

**원제:** IV. Multi-Module Systems and Graph Transformer Networks  
**출처:** LeCun et al. (1998), *Gradient-Based Learning Applied to Document Recognition*, Section IV (pp. 16–19).  
**학습 목표:** 다중 모듈 학습의 원리와 GTN의 특징을 이해하고, 일반 CNN과 손글씨 문자열 인식 시스템의 모듈을 구분한다.

> **한 문장 핵심:** CNN은 개별 글자의 특징을 추출하고 분류하며, GTN은 여러 문자 분할·인식 후보를 그래프로 표현하고 변환하는 모듈들을 연결하여 더 복잡한 인식 시스템을 구성한다.

## 1. 핵심 내용 10가지 — 쉬운 예시와 보충 설명

### ① 다중 모듈 시스템(Multi-Module System)
- **핵심:** 서로 다른 기능의 모듈을 연결하여 하나의 복잡한 인식 시스템을 만든다.
- **쉬운 예:** 학교에서 담임·교과전담·상담교사가 서로 다른 업무를 수행하면서 학생 교육이라는 공동 목표를 위해 협력하는 것과 비슷하다.
- **보충:** LeNet-5도 합성곱·서브샘플링·완전연결·RBF 모듈을 결합한 다중 모듈 시스템이다.

### ② 모듈(Module)
- **핵심:** 특정 입력을 받아 정해진 계산을 수행하고 출력을 내는 처리 단위다.
- **쉬운 예:** 합성곱 모듈은 숫자 '8' 이미지에서 곡선과 고리 같은 특징을 찾는다.
- **보충:** 모듈마다 학습할 매개변수가 있을 수도, 없을 수도 있다. 손실함수 역시 모듈로 취급할 수 있다.

### ③ 모듈 연결과 계산 흐름
- **핵심:** 한 모듈의 출력이 다음 모듈의 입력이 된다. 하나의 출력이 여러 모듈로 나뉘어 전달될 수도 있다.
- **쉬운 예:** 이미지에서 특징을 추출한 뒤 그 특징을 숫자 분류 모듈에 전달한다.
- **보충:** 논문 그림 14에서는 일부 모듈이 병렬로 계산된 뒤 결과가 결합된다.

### ④ 그래프 구조(Graph Structure)
- **핵심:** 모듈과 연결 관계를 방향 그래프로 나타내면 계산 순서를 정의할 수 있다.
- **쉬운 예:** `입력 → 특징 추출 → 분류 → 손실 계산`처럼 화살표로 표현한다.
- **보충:** 여기서 **모듈 연결을 나타내는 계산 그래프**와 GTN이 **데이터로 주고받는 후보 해석 그래프**는 구별해야 한다.

### ⑤ 순전파(Forward Propagation, fprop)
- **핵심:** 입력에서 출력 방향으로 계산하여 예측값과 손실을 구한다.
- **쉬운 예:** 손글씨 '8'을 넣었더니 신경망이 '3'이라고 예측한다.
- **보충:** 객체지향 구현에서는 각 모듈의 `fprop` 메서드를 적절한 순서로 호출한다.

### ⑥ 역전파(Backward Propagation, bprop)
- **핵심:** 최종 손실의 기울기를 계산 순서의 역방향으로 전달한다.
- **쉬운 예:** '8'을 '3'으로 잘못 예측했다면 그 오류가 분류 모듈을 거쳐 특징 추출 모듈까지 전달된다.
- **보충:** 역전파는 단순한 층별 신경망뿐 아니라 기울기를 계산할 수 있는 다양한 모듈 연결 구조에도 적용된다.

### ⑦ 전체 학습(Global Training)
- **핵심:** 최종 인식 성능을 기준으로 연결된 모듈의 학습 가능한 매개변수를 함께 조정한다.
- **쉬운 예:** 글자를 하나씩 맞히는 데만 집중하지 않고 최종 단어를 정확히 읽도록 인식기를 학습한다.
- **보충:** 모든 모듈이 반드시 학습되는 것은 아니다. 과분할처럼 휴리스틱으로 수행하는 단계도 있다.

### ⑧ 객체지향 구현(Object-Oriented Implementation)
- **핵심:** 모듈을 객체로 구현하고 순전파·역전파 메서드를 정의한다.
- **쉬운 예:** 각 모듈에 `fprop()`은 결과 계산, `bprop()`은 기울기 전달이라는 공통 기능을 둔다.
- **보충:** 작은 모듈을 조합해 복잡한 모듈을 만들 수 있어 시스템 설계와 재사용이 쉬워진다.

### ⑨ 특수 모듈(Special Modules)
- **핵심:** 행렬곱, 시그모이드, 합성곱, 서브샘플링, RBF, Softmax, 손실함수 등 여러 연산을 모듈로 사용할 수 있다.
- **쉬운 예:** 합성곱으로 곡선을 찾고, RBF 출력층으로 글자별 불일치 정도를 계산한다.
- **보충:** 논문 속 LeNet-5는 **RBF 출력층**을 사용한다. Softmax는 제Ⅳ장에서 소개하는 일반적인 모듈의 예이지 LeNet-5의 실제 출력층이라는 뜻은 아니다.

### ⑩ 그래프 변환 네트워크(GTN)의 의의
- **핵심:** 고정 크기 벡터 대신 여러 가능한 해석을 담은 **그래프**를 입력·출력으로 주고받는 모듈들을 연결한다.
- **쉬운 예:** 붙어 쓴 '12'에서 글자 경계를 하나로 단정하지 않고 여러 분할·인식 후보를 유지한 뒤 적절한 해석을 선택한다.
- **보충:** GTN의 그래프는 경로별 후보와 비용을 표현할 수 있으며, 그래프에 실린 수치 정보에 대한 기울기를 역전파할 수 있다. 여기서 Transformer는 오늘날의 Transformer 언어모델과 다른 의미다.

## 2. 일반적인 CNN과 논문의 손글씨 처리 모듈 비교

### A. 일반적인 CNN: 개별 글자 인식

| 구성 요소 | 역할 | 쉬운 예 |
|---|---|---|
| 합성곱층(Convolution) | 국소 특징 추출 | '8'의 곡선과 고리 찾기 |
| 서브샘플링/풀링(Subsampling/Pooling) | 특징맵 축소, 위치 변화에 대한 강건성 향상 | 글자가 조금 이동해도 특징 유지 |
| 완전연결층(Fully Connected) | 추출한 특징 결합 | 위아래 고리의 조합 판단 |
| 출력 분류층 | 문자별 점수 계산 | '3'과 '8' 중 하나 선택 |
| 손실함수·역전파 | 오차 계산과 학습 | 오인식을 줄이도록 가중치 조정 |

**논문에서의 정확한 구현:** LeNet-5는 `입력 → C1 → S2 → C3 → S4 → C5 → F6 → RBF 출력` 구조다. 일반적인 현대 CNN의 Softmax 분류와 달리 LeNet-5의 출력은 RBF 기반이다.

### B. 논문의 연속 손글씨 인식: GTN 기반 처리

> 다음은 제Ⅳ장의 GTN 원리를 **제Ⅴ장의 손글씨 문자열 인식 예시**까지 연결한 설명이다. 제Ⅳ장에 모든 처리 단계가 상세히 등장하는 것은 아니다.

| 모듈·자료구조 | 역할 | 쉬운 예 |
|---|---|---|
| 과분할(Heuristic Over-Segmentation) | 글자 경계 후보를 여러 개 생성하는 처리 단계 | 붙어 쓴 '12'를 여러 위치에서 잘라보기 |
| 분할 그래프(Segmentation Graph) | 가능한 문자 분할을 경로로 표현하는 **자료구조** | 서로 다른 분할 후보들을 보관 |
| 인식 변환기(Recognition Transformer) | 후보 문자 이미지에 인식기를 적용해 해석 그래프 생성 | 각 조각이 '1', '2', '7' 중 무엇인지 평가 |
| CNN 문자 인식기 | 각 후보 이미지의 문자별 비용 계산 | 특정 조각이 '2'일 가능성 평가 |
| 해석 그래프(Interpretation Graph) | 분할과 문자 해석 후보를 담는 **자료구조** | '12' 또는 '17' 등의 경로 유지 |
| Viterbi 변환기 | 누적 비용이 가장 작은 해석 경로 추출 | 여러 경로 중 최적의 문자열 선택 |
| 전역 학습 | 최종 문자열 성능을 기준으로 학습 가능한 모듈 최적화 | 개별 글자 오류보다 전체 단어 오류를 줄이도록 학습 |

**주의:** 분할 그래프와 해석 그래프는 모듈이 아니라 **모듈 사이에 전달되는 그래프 형태의 데이터**다. 과분할은 휴리스틱 단계이므로 모든 과정이 미분 가능하거나 자동 학습되는 것은 아니다.

### C. 차이점 한눈에 보기

| 비교 기준 | 일반 CNN | GTN 기반 손글씨 문자열 시스템 |
|---|---|---|
| 주요 문제 | **이 글자는 무엇인가?** | **어디서 나누고 어떻게 읽을 것인가?** |
| 주요 입력 | 개별 문자 이미지 | 연결된 문자·단어 이미지와 분할 후보 |
| 전달 정보 | 주로 특징맵·벡터 | 여러 후보 경로와 수치 비용을 담은 그래프 |
| 핵심 기술 | 합성곱·서브샘플링·분류 | 과분할·인식 변환·Viterbi 경로 선택 |
| 학습 관점 | 문자 인식 오류 최소화 | 전체 문자열 인식 목표에 따른 모듈 학습 가능 |
| 관계 | 글자 인식 기능 담당 | CNN을 구성 요소로 포함할 수 있는 상위 시스템 |

## 3. 그림 14와 그림 15 — 강의 핵심 그림

**그림 14. A trainable system composed of heterogeneous modules**  
여러 종류의 모듈을 그래프로 연결하고, 순전파와 역전파를 통해 학습할 수 있음을 보여준다. **다중 모듈 학습의 원리**를 설명하는 그림이다.

**그림 15. Traditional neural networks ... / Multi-Layer Graph Transformer Networks ...**  
기존 신경망은 계층 사이에 주로 고정 크기 벡터를 전달하지만, GTN은 수치 정보가 담긴 간선을 가진 그래프를 변환한다. **GTN의 독창성**을 설명하는 가장 핵심적인 그림이다.

## 4. 예시로 정리하는 전체 과정

**개별 숫자 '8' 인식(CNN):**  
`손글씨 '8' 이미지 → 합성곱 특징 추출 → 서브샘플링 → 특징 결합 → RBF 분류 → 숫자 '8'`

**붙어 쓴 '12' 인식(GTN 기반 시스템):**  
`손글씨 '12' 이미지 → 여러 분할 후보 생성 → 분할 그래프 → CNN으로 후보 문자 평가 → 해석 그래프 → Viterbi 최적 경로 → '12'`

이때 최종 오류에 대한 기울기를 계산 가능한 모듈로 전달하면 시스템의 관련 매개변수를 함께 학습할 수 있다.

## 5. 강의 마무리 — 꼭 기억할 3문장

1. **CNN은 개별 문자의 특징을 추출하고 분류하는 기술이다.**
2. **GTN은 여러 후보 해석을 그래프로 표현하고 변환하는 모듈을 연결한 시스템이다.**
3. **이 논문의 핵심 공헌은 역전파를 복잡한 다중 모듈·그래프 기반 인식 시스템으로 확장한 데 있다.**
