# Ⅲ. Results and Comparison with Other Methods
## 실험 결과 및 다른 인식 방법과의 비교

**출처:** Yann LeCun 외, *Gradient-Based Learning Applied to Document Recognition*, Proceedings of the IEEE, 1998, 제Ⅲ장.

## 1. 핵심 내용 10줄 요약

1. **연구 목적:** LeNet-5의 손글씨 숫자 인식 성능을 다양한 분류 방법과 비교한다.
2. **MNIST 데이터셋:** NIST의 자료를 재구성하여 학습 이미지 60,000개와 평가 이미지 10,000개를 사용했다.
3. **이미지 전처리:** 손글씨 숫자를 20×20픽셀 범위에 맞춘 뒤 28×28픽셀 영역의 중앙에 배치했다.
4. **반복 학습:** 60,000개 학습 데이터를 여러 차례 반복했으며, 약 10~12회 후 테스트 오류율이 안정화되었다.
5. **기본 성능:** 데이터 변형 없이 학습한 LeNet-5의 테스트 오류율은 약 **0.95%**였다.
6. **데이터 증강:** 이동·확대·축소·압축·기울이기 등으로 숫자 이미지를 변형하여 학습 사례를 늘렸다.
7. **증강 효과:** 변형된 이미지를 이용해 학습한 LeNet-5의 테스트 오류율은 약 **0.8%**로 낮아졌다.
8. **비교 대상:** 선형 분류기, 최근접 이웃(K-NN), PCA, RBF, 완전연결 신경망, SVM, Tangent Distance 등을 비교했다.
9. **최저 오류율:** 여러 LeNet-4를 결합한 Boosted LeNet-4가 약 **0.7%**의 테스트 오류율을 보였다.
10. **결론:** 인식 정확도뿐 아니라 계산량, 메모리 요구량, 변형과 잡음에 대한 강인성도 중요하며 CNN은 이들 측면에서 경쟁력이 있었다.

## 2. 꼭 알아야 할 핵심 개념

| 핵심 개념 | 뜻 | 쉬운 예시 |
|---|---|---|
| MNIST | 손글씨 숫자 0~9의 학습·평가 데이터셋 | 여러 사람이 쓴 숫자 '3'을 모아 학습 |
| 오류율(Error Rate) | 전체 평가 이미지 중 잘못 분류한 비율 | 1,000개 중 8개 오답이면 0.8% |
| 데이터 증강(Data Augmentation) | 기존 이미지를 변형해 학습 사례를 다양화 | '7'을 기울이거나 좌우로 이동 |
| 일반화(Generalization) | 학습에 없던 새 이미지도 올바르게 인식하는 능력 | 처음 보는 사람의 필체를 인식 |
| 과적합(Overfitting) | 학습 데이터에는 잘 맞지만 평가 데이터에는 약한 현상 | 연습문제만 외워 새 문제를 틀림 |
| 벤치마크(Benchmark) | 동일한 조건에서 알고리즘 성능을 비교 | 같은 시험지로 여러 모델을 평가 |
| Boosting | 여러 분류기를 결합해 오류를 줄이는 방법 | 서로 다른 채점 결과를 종합 |
| SVM | 분류 집단 사이의 경계를 찾는 방법 | '3'과 '8'의 구분 경계 학습 |
| Tangent Distance | 작은 기하학적 변형을 고려해 이미지 사이의 거리를 계산 | 조금 기울어진 '5'도 비슷한 모양으로 취급 |
| 거부율(Rejection Rate) | 불확실한 입력의 판정을 보류하는 비율 | 애매한 숫자를 사람에게 재확인 요청 |
| 계산량·메모리 | 모델 실행에 필요한 연산과 저장 공간 | 정확도가 같으면 빠르고 가벼운 모델이 유리 |
| 불변성·잡음 강인성 | 크기·위치·기울기·잡음이 달라도 잘 인식하는 성질 | 위치가 바뀌거나 흐릿한 '8'을 인식 |

## 3. 그림 4~9 설명

### 그림 4. MNIST 손글씨 숫자 데이터 사례

<img width="484" height="465" alt="image" src="https://github.com/user-attachments/assets/efb684d1-1052-4dd2-ae8d-8a7390bcdb52" />

MNIST 테스트 데이터에서 추출한 손글씨 숫자 이미지의 예시다. 사람마다 필체와 굵기, 기울기가 다르지만 크기 정규화와 중앙 배치를 통해 비교적 일관된 입력 형식으로 만들었다.

- **예시:** 여러 사람이 다르게 쓴 숫자 '5'를 모두 같은 정답으로 학습한다.
- **핵심:** 다양한 실제 데이터와 적절한 전처리가 중요하다.

### 그림 5. 학습 반복 횟수에 따른 오류율 변화

<img width="516" height="442" alt="image" src="https://github.com/user-attachments/assets/d447cfb9-6530-4004-864a-2b1409705a4b" />

가로축은 학습 데이터 전체를 반복한 횟수, 세로축은 오류율이다. 학습 초기에는 오류율이 빠르게 줄고, 약 10~12회 반복 후 테스트 오류율이 약 0.95%로 안정화된다. 그림 설명에 따르면 훈련 오류율은 학습 도중 실시간으로 평균을 내므로 일부 구간에서는 테스트 오류율보다 높게 보일 수 있다.

- **예시:** 문제집을 반복해서 풀면 처음에는 실력이 빠르게 늘지만 이후 향상 폭이 작아진다.
- **핵심:** 학습 수렴과 훈련·테스트 오류율의 차이를 이해한다.

### 그림 6. 학습 데이터 크기와 오류율의 관계

<img width="516" height="404" alt="image" src="https://github.com/user-attachments/assets/b85d2143-f490-482d-a255-80b536878120" />

학습 이미지 수를 15,000개, 30,000개, 60,000개로 늘릴수록 테스트 오류율이 낮아지는 경향을 보여준다. 인위적으로 변형한 학습 데이터를 활용하면 테스트 오류율이 약 0.8%로 더 낮아진다. 평가용 이미지는 변형하지 않았다.

- **예시:** 100개의 필체보다 1,000개의 다양한 필체를 학습한 모델이 새로운 필체를 더 잘 구별할 수 있다.
- **핵심:** 데이터의 양과 다양성이 일반화 성능에 영향을 준다.

### 그림 7. 데이터 증강을 통한 숫자 변형 사례

<img width="516" height="448" alt="image" src="https://github.com/user-attachments/assets/0e7f5637-b49f-4f23-856a-d316cff04ea3" />

숫자 0~9의 학습 이미지에 이동, 크기 변화, 압축, 전단(shearing) 등 기하학적 변형을 적용한 예시다. 숫자의 정답은 유지하면서 모양을 다양하게 만들어 학습에 활용한다.

- **예시:** 똑바로 쓴 '7', 기울어진 '7', 폭이 좁은 '7'을 같은 숫자로 학습한다.
- **핵심:** 데이터 증강은 새로운 손글씨를 직접 수집하지 않고도 학습 사례를 확장한다.

### 그림 8. LeNet-5가 잘못 인식한 82개 숫자

<img width="526" height="497" alt="image" src="https://github.com/user-attachments/assets/13703d85-aa15-4ff0-abc4-5d7dc8149f1d" />

테스트 데이터 10,000개 중 잘못 인식한 **82개 숫자 이미지**를 보여준다. 이미지 아래의 표기는 **왼쪽이 실제 정답, 오른쪽이 모델의 예측**이다. 일부는 사람도 구별하기 어려울 정도로 모호하고, 일부는 학습 데이터에 드물게 등장하는 필체다.

- **예시:** 숫자 '4'를 '9'처럼 쓰면 모델이 혼동할 수 있다.
- **핵심:** 오류 사례를 분석하면 어떤 필체를 추가 학습해야 할지 알 수 있다.

### 그림 9. 여러 숫자 인식 알고리즘의 오류율 비교

<img width="758" height="522" alt="image" src="https://github.com/user-attachments/assets/560f2c09-2c97-4d20-81cf-3d7926db4575" />


같은 MNIST 테스트 자료에서 여러 알고리즘의 오류율을 비교한 막대그래프다. 막대가 짧을수록 오류율이 낮다. 논문에서는 LeNet 계열 CNN이 높은 성능을 보였고, 변형 데이터 학습과 Boosting이 성능 개선에 기여했다.

| 비교 모델 | 테스트 오류율 |
|---|---:|
| 선형 분류기 | 12.0% |
| K-NN (기본 유클리드 거리) | 5.0% |
| 완전연결 신경망 (은닉 뉴런 300개) | 4.7% |
| LeNet-1 | 1.7% |
| LeNet-4 | 1.1% |
| LeNet-5 (기본) | 0.95% |
| LeNet-5 (변형 데이터 학습) | 0.8% |
| Boosted LeNet-4 (변형 데이터 학습) | 0.7% |

> **주의:** 위 수치는 1998년 논문에서 보고한 당시 실험 결과이며, 현대의 최신 인식 모델 성능을 의미하지 않는다. 모델마다 데이터 전처리나 증강 조건이 일부 다르므로 비교 시 이를 고려해야 한다.

- **예시:** 동일한 10,000개 숫자를 평가할 때 오류율 0.8%는 약 80개를 잘못 분류한다는 뜻이다.
- **핵심:** CNN의 구조적 설계와 데이터 증강은 손글씨 숫자 인식 정확도 향상에 유리했다.

## 4. 그림 4~9 한눈에 정리

| 그림 | 핵심 개념 | 핵심 메시지 |
|---|---|---|
| 4 | MNIST | 다양한 손글씨 자료와 전처리가 필요하다. |
| 5 | 학습 수렴 | 반복 학습으로 오류율이 감소하고 안정화된다. |
| 6 | 데이터 크기 | 학습 데이터가 많아질수록 일반화가 개선된다. |
| 7 | 데이터 증강 | 다양한 형태의 숫자를 학습하면 인식 성능이 좋아진다. |
| 8 | 오류 분석 | 모호하거나 드문 필체는 여전히 오류를 일으킨다. |
| 9 | 모델 비교 | CNN은 다른 여러 분류기보다 낮은 오류율을 보였다. |

## 5. 강의에서 강조할 핵심 개념 5가지

1. **MNIST:** 무엇으로 학습하고 평가했는가?
2. **데이터 증강:** 학습 데이터를 어떻게 다양하게 만들었는가?
3. **일반화:** 처음 보는 필체를 얼마나 잘 인식하는가?
4. **모델 성능 비교:** 어떤 모델이 얼마나 정확했는가?
5. **불변성과 잡음 강인성:** 숫자의 모양과 위치가 달라져도 인식할 수 있는가?

**종합 결론:** 제Ⅲ장은 **학습 데이터 확보 → 반복 학습 → 데이터 증강 → 오류 분석 → 다른 모델과 비교**라는 실험 흐름을 통해 CNN의 인식 성능과 효율성을 검증한다.
