# ImageNet · AlexNet · Google Cat 비교

> **핵심:** ImageNet은 이미지 데이터셋, AlexNet은 지도학습 기반 CNN 모델, Google Cat은 대규모 비지도 특징학습 연구의 비공식 별칭이다.

## 1. 한눈에 이해하기

- **ImageNet(2009):** 수많은 이미지에 사물 범주를 표시해 이미지 인식 연구의 학습·평가 기반을 제공한 데이터셋이다. 쉽게 말해 **시험문제집과 정답지**에 해당한다.
- **AlexNet(2012):** ImageNet의 라벨이 있는 이미지로 학습하고 2012년 ILSVRC에서 우수한 성적을 낸 **CNN 모델**이다. 시험문제를 공부하고 답을 맞히는 **학생**에 비유할 수 있다.
- **Google Cat(2012):** Quoc V. Le, Andrew Ng 등 연구진의 논문 *Building High-level Features Using Large Scale Unsupervised Learning*을 가리키는 **비공식 별칭**이다. 정답 없는 대량의 이미지에서도 얼굴과 고양이 같은 고차원 특징을 학습할 수 있음을 보여주었다.

## 2. 세 연구의 비교

| 구분 | ImageNet | AlexNet | Google Cat |
|---|---|---|---|
| 등장 연도 | 2009 | 2012 | 2012 |
| 정체 | 대규모 이미지 데이터셋 | 심층 합성곱 신경망(CNN) | 대규모 비지도 특징학습 연구 |
| 주요 인물 | Jia Deng, Fei-Fei Li 등 | Alex Krizhevsky, Ilya Sutskever, Geoffrey Hinton | Quoc V. Le, Andrew Ng, Jeff Dean 등 |
| 핵심 질문 | 다양한 사물의 이미지 인식을 어떻게 학습·평가할까? | CNN으로 이미지 분류 정확도를 얼마나 높일 수 있을까? | 정답을 알려주지 않아도 고차원 특징을 학습할 수 있을까? |
| 데이터 | 사물 범주가 표시된 대규모 이미지 | ImageNet의 라벨이 있는 이미지 | 유튜브에서 추출한 1,000만 장의 이미지 등 |
| 학습 방식 | 데이터셋 자체는 학습 모델이 아님 | 지도학습 | 비지도 특징학습 후 분류 평가에서는 라벨 활용 |
| 대표 성과 | 대규모 시각 인식 연구의 기반 | ILSVRC 2012 이미지 분류 우승 | 얼굴·고양이 얼굴·인체에 선택적으로 반응하는 뉴런 발견 |

## 3. 고양이 사진으로 이해하기

### ImageNet: 사진과 정답을 제공

- 사진: 고양이
- 정답 라벨: `cat` 또는 구체적인 고양이 범주
- 목적: 인공지능이 학습하고 성능을 검증할 수 있도록 자료를 제공

### AlexNet: 정답을 보고 가중치를 수정

1. 고양이 사진을 입력한다.
2. CNN 필터가 선·색상·모양 등 다양한 시각적 패턴을 추출한다.
3. 여러 층을 거쳐 분류에 유용한 복잡한 특징을 형성한다.
4. 모델이 사물 범주를 예측한다.
5. 예측과 정답 라벨을 비교해 오차를 계산하고 역전파로 가중치를 조정한다.

**예:** 고양이 사진을 다른 동물로 예측했다면, 학습 과정에서 오차를 줄이는 방향으로 필터 가중치를 바꾼다.

### Google Cat: 정답 없이 특징을 학습

1. 연구진이 유튜브 영상에서 이미지 1,000만 장을 수집한다.
2. 이미지에 `고양이`, `사람 얼굴` 같은 정답을 붙이지 않고 학습한다.
3. 9층의 국소 연결 희소 오토인코더가 이미지의 특징 표현을 학습한다.
4. 학습이 끝난 뒤 뉴런의 반응을 조사하자 얼굴·고양이 얼굴·인체에 선택적으로 반응하는 뉴런이 발견된다.

**주의:** 인공지능이 인터넷을 스스로 돌아다니며 이미지를 수집한 실험은 아니다. 연구진이 데이터를 마련했으며, **'스스로'는 정답 라벨 없이 특징을 학습했다는 의미**다.

## 4. 주요 실험 결과

### AlexNet: ILSVRC 2012

| 항목 | Top-5 오류율 |
|---|---:|
| AlexNet | 약 15.3% |
| 당시 2위 참가 시스템 | 약 26.2% |

**Top-5 오류율:** 모델이 제시한 상위 5개 후보에 정답이 들어 있지 않은 비율이다. 낮을수록 성능이 좋다.

### Google Cat: 논문에 보고된 성능

| 평가 대상 | 정확도 |
|---|---:|
| 사람 얼굴과 다른 이미지 구별 | 81.7% |
| 고양이 얼굴과 다른 이미지 구별 | 74.8% |
| 사람 신체와 다른 이미지 구별 | 76.7% |

이 수치는 학습 후 선택한 뉴런의 특정 이진 구별 실험 결과이며, AlexNet의 ImageNet Top-5 오류율과 **직접 비교할 수 없다**.

Google Cat 연구는 ImageNet의 약 20,000개 범주 분류에서도 **15.8%의 정확도**를 기록하여 당시 비교 대상의 9.3%보다 상대적으로 약 70% 높은 결과를 보고했다. 이 분류 실험에는 라벨을 활용한 분류기 학습과 미세조정이 포함된다.

## 5. 서로 어떤 관계인가?

```text
ImageNet (2009): 대규모 이미지 인식 연구의 데이터 기반
          │
          ├── AlexNet (2012)
          │      └─ ImageNet 라벨을 활용한 CNN 지도학습
          │         → ILSVRC 2012 우승
          │
          └── Google Cat (2012)
                 └─ 유튜브 이미지로 비지도 특징학습
                    → ImageNet 분류 과제로 유용성 평가
```

- **공통점:** 대규모 이미지 데이터와 신경망을 통해 시각 인식의 발전을 추구했다.
- **차이점:** AlexNet은 정답 라벨을 활용한 분류 성능 향상에, Google Cat은 정답 없는 이미지에서 고차원 특징이 나타나는지에 초점을 맞췄다.
- **관계의 한계:** Google Cat이 AlexNet의 직접적인 선행 단계라는 뜻은 아니다. 두 연구는 2012년에 등장한 서로 다른 접근법이다.

## 6. CNN 구조와 Google Cat 구조의 차이

**AlexNet의 CNN:** 합성곱 필터의 **가중치를 여러 이미지 위치에서 공유**한다. 같은 필터가 이미지의 여러 위치에서 동일한 유형의 특징을 탐지하도록 학습한다.

**Google Cat의 국소 연결망:** 각 뉴런이 이미지의 작은 영역에 연결되는 **국소 수용영역**을 사용하지만, 일반적인 합성곱과 달리 **위치별 가중치를 공유하지 않는다**. 필터링·L2 풀링·국소 대비 정규화를 반복하는 9층 구조를 사용한다.

따라서 두 모델을 모두 단순히 'CNN'이라고 부르는 것은 정확하지 않다.

## 7. 연구사적 의의와 한계

**ImageNet의 의의:** 비교 가능한 대규모 이미지 인식 과제를 제공하여 알고리즘 발전을 촉진했다.

**AlexNet의 의의:** GPU를 활용한 심층 CNN이 대규모 이미지 분류에서 매우 효과적이라는 사실을 강하게 입증했다.

**Google Cat의 의의:** 정답이 없는 이미지에서도 얼굴·고양이 얼굴 같은 고차원 특징에 반응하는 표현을 학습할 수 있음을 보여주었다.

**공통 한계:** 높은 인식 성능이나 특징 학습 능력이 곧 인간과 같은 의식적 이해나 주관적 경험을 증명하지는 않는다.

## 8. 핵심 요약 5줄

1. **ImageNet**은 대규모 이미지 학습과 평가에 필요한 데이터를 제공했다.
2. **AlexNet**은 ImageNet의 정답이 있는 이미지로 CNN을 학습해 2012년 대회에서 우승했다.
3. **Google Cat**은 정답이 없는 대량의 이미지에서 고차원 시각 특징을 학습할 수 있음을 보여주었다.
4. AlexNet은 **지도학습 기반 분류 성능**, Google Cat은 **비지도 특징학습의 가능성**을 강조했다.
5. 세 연구는 대규모 데이터와 딥러닝이 현대 컴퓨터 비전 발전에 기여한 서로 다른 측면을 보여준다.
