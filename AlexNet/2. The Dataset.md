# 2. 데이터셋 (The Dataset)

## ImageNet 데이터셋 요약

> **논문**: A. Krizhevsky, I. Sutskever, G. E. Hinton, "ImageNet Classification with Deep Convolutional Neural Networks", *NeurIPS*, 2012. (AlexNet)

> 💡 **한 줄 요약**
> 웹에서 모은 수천만 장의 사진에 사람이 직접 이름표를 붙인 **ImageNet**으로 학습합니다. 이미지는 **256×256** 크기로 통일하고, 성능은 **Top-1 / Top-5 오류율**로 평가합니다.

---

## 1. 📦 데이터셋 개요

ImageNet은 **1,500만 장 이상의 레이블이 붙은 고해상도 이미지**로 구성된 대규모 데이터셋입니다.

- **수집**: 웹에서 이미지를 모았습니다.
- **레이블링**: 아마존 **Mechanical Turk**(크라우드소싱 서비스)를 통해 사람이 직접 분류했습니다.
- **카테고리 수**: 약 **22,000개**

### ILSVRC에서 사용한 데이터

ImageNet 중 **1,000개 카테고리**를 골라, 카테고리마다 **약 1,000장**씩 사용했습니다.

| 구분 | 이미지 수 | 용도 |
|---|---:|---|
| 🏋️ **훈련** (Training) | 약 **1,200,000**장 | 모델 학습 |
| 🔍 **검증** (Validation) | **50,000**장 | 학습 중 성능 확인 |
| 📝 **테스트** (Test) | **150,000**장 | 최종 성능 평가 |

---

## 2. 🏆 ILSVRC

**ImageNet Large-Scale Visual Recognition Challenge**: 2010년부터 매년 열린 이미지 인식 대회로, ImageNet의 일부를 사용합니다.

| 대회 | 테스트 레이블 공개 | 이 논문에서의 활용 |
|---|:---:|---|
| **ILSVRC-2010** | ✅ 공개 | 테스트 레이블이 공개된 **유일한 버전** → 대부분의 실험에 사용 |
| **ILSVRC-2012** | ❌ 비공개 | 대회에 직접 참가해 결과 보고 (테스트 대신 검증 세트 오류율을 함께 제시) |

---

## 3. 🖼️ 이미지 전처리

ImageNet 이미지는 크기가 제각각이지만, 신경망은 **고정된 크기의 입력**을 요구합니다. 그래서 다음과 같이 전처리했습니다.

### ① 다운샘플링: 256×256으로 통일

```
  원본 (예: 500×375)
        │  짧은 쪽을 256으로 맞춰 축소 → 341×256
        ▼
  ┌───────────────┐
  │   ┌───────┐   │
  │   │256×256│   │   ← 가운데 부분만 잘라냄 (중앙 크롭)
  │   └───────┘   │
  └───────────────┘
```

1. 직사각형 이미지의 **짧은 쪽 길이가 256**이 되도록 비율을 유지하며 크기를 조정합니다.
2. 결과 이미지의 **중앙에서 256×256 패치**를 잘라냅니다.

### ② 평균 빼기

- 각 픽셀 값에서 **훈련 세트 전체의 평균 활동값**(mean activity)을 뺍니다.
- 이것 외에 다른 전처리는 하지 않았습니다.

### ③ 입력

- 신경망은 이렇게 처리한 **원시(raw) RGB 픽셀 값**을 그대로 받아 학습합니다.
- 사람이 설계한 특징(에지, 색상 히스토그램 등)을 따로 뽑지 않습니다.

---

## 4. 📊 오류율 보고 방식

ImageNet에서는 관례적으로 **두 가지 오류율**을 함께 보고합니다.

| 지표 | 정의 | 쉬운 비유 |
|---|---|---|
| **Top-1 오류율** | 모델이 **가장 확률이 높다고 본 1개**가 정답이 아닌 비율 | 정답을 **한 번에** 맞혀야 함 |
| **Top-5 오류율** | 정답이 모델이 고른 **상위 5개 후보 안에 없는** 비율 | **다섯 번** 안에만 맞히면 됨 |

> **예시**: 정답이 '시베리안 허스키'인 사진에 대해 모델이 [알래스칸 말라뮤트, 시베리안 허스키, 늑대, 에스키모견, 사모예드] 순으로 예측했다고 합시다.
> - **Top-1**: 1위가 '말라뮤트'이므로 ❌ 오답
> - **Top-5**: 상위 5개 안에 '허스키'가 있으므로 ✅ 정답
>
> 1,000개 카테고리 중에는 이처럼 비슷한 종류가 많기 때문에, Top-5 오류율도 함께 봅니다.
