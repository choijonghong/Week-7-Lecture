# 📚 AlexNet 논문 설명 자료 (2012)
## 1. 개요: ImageNet 논문과 AlexNet
논문 제목: ImageNet Classification with Deep Convolutional Neural Networks (일반적으로 AlexNet으로 알려짐)
발표 연도: 2012년
저자:
Alex Krizhevsky (알렉스 크리제프스키, 박사과정)
Ilya Sutskever (일리아 수츠케버, 박사과정)
Geoffrey Hinton (제프리 힌튼, 교수)
소속: 토론토 대학교 (University of Toronto)
## 2. ILSVRC 대회 배경
대회 명칭: ImageNet Large Scale Visual Recognition Challenge (ILSVRC)
대회 성격: 비전(Vision) 분야의 올림픽이라 불릴 정도로 권위 있는 이미지 인식 대회였습니다.
우승 조건: 이미지 인식 오류율이 1%라도 낮으면 우승 트로피를 주던 경쟁적인 대회였습니다.
기존 우승팀: 2010년부터 시작된 이 대회에서 2011년에는 제록스 연구소의 SVM 머신러닝 기법이 우승했습니다.
## 3. AlexNet 팀의 도전과 GPU 도입
결심: 알렉스 크리제프스키와 일리아 수츠케버는 ImageNet 대회에 출전하여 우승하기로 마음먹고 연구를 시작합니다.
데이터 규모: 대회의 데이터는 무려 1,000만 장 이상의 이미지를 포함하고 있었습니다.
GPU 활용: 제한된 시간 내에 대규모 학습 데이터에 대한 성능을 높이기 위해 자신들의 모델에 GPU(그래픽 처리 장치) 기능을 추가했습니다.
제프리 힌튼 교수의 조언: 행렬 계산에 GPU가 적합하다고 조언합니다.
선행 연구: (독일) 위르겐 슈미트후버 연구팀은 이미 2010년부터 GPU를 사용하고 있었습니다.
## 4. 모델 학습의 난관: 오버피팅 (Overfitting) 문제
문제점: AlexNet 모델을 학습시키는 과정에서 오버피팅(과적합) 문제가 발생했습니다.
오버피팅이란? 학습 데이터에 대해서는 오류가 없거나 매우 낮게 나오지만, 실제 데이터(새로운 데이터)에서는 오류가 높게 발생하는 현상입니다. (학습을 많이 시킨다고 무조건 좋은 모델이 나오는 것은 아님)
## 5. 획기적인 오버피팅 해결책: 드롭아웃 (Dropout)
해결사: 이 고질적인 오버피팅 문제를 해결한 사람은 연구실 후배인 니티시 스리바스타바였습니다.
드롭아웃 아이디어: 모든 노드를 계산하지 않고, 랜덤하게 일부 노드의 계산값을 버리고(신경망의 일부를 비활성화) 계산하는 방식입니다.
이는 마치 식물을 키울 때 솎아주면 더 잘 자라는 것과 같은 이치로 비유됩니다.
결과: 이 아이디어는 니티시의 석사 논문으로 발표되었으며, 네 사람(알렉스, 일리아, 힌튼, 니티시)의 특허로 등록됩니다.
## 6. 추가 성능 향상: ReLU 활성화 함수
활성화 함수 교체: 요슈아 벤지오 연구실의 획기적인 성능을 가진 ReLU (Rectified Linear Unit) 활성화 함수로 모델을 바꿉니다.
개선 효과: 성능이 훨씬 더 향상됩니다. (AlexNet 개발 당시에는 ReLU가 왜 좋은지 정확히 모르고 사용했으나, 써보니 좋았다는 후문)
추가 기여: Alex Krizhevsky는 ReLU를 사용하는 초기화 방법도 개발했습니다.
상대 연구팀: 자비에르 글로롯은 요슈아 벤지오 연구실 소속으로, ReLU의 초기화 방식을 연구했습니다.
## 7. ILSVRC 2012 대회 우승
결과: 드디어 2012년 ILSVRC 대회에 출전한 AlexNet은 놀라운, 경이적인 기록으로 우승을 차지합니다.
오류율 비교 (Error, 5 guesses 기준):
AlexNet (SuperVision): 약 0.15315 (15.315%)
2위 (ISI): 약 0.26172 (26.172%)
의미: 기존의 오류율이 1%만 낮아도 우승하는 대회에서, AlexNet은 무려 10% 이상의 오류율을 낮추는 (1% 향상도 어려운데 무려 10%씩이나!) 압도적인 성능을 보여주며 딥러닝 시대의 서막을 열었습니다.
