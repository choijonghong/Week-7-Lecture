# 3.5 전체 구조 (Overall Architecture)

> **논문**: A. Krizhevsky, I. Sutskever, G. E. Hinton, "ImageNet Classification with Deep Convolutional Neural Networks", *NeurIPS*, 2012. (AlexNet)

> 💡 **한 줄 요약**
> AlexNet은 **합성곱 층 5개 + 완전 연결 층 3개**, 모두 **8개의 학습 층**으로 이루어집니다. 네트워크 전체를 **GPU 두 대에 반씩** 나눠 올리고, 두 GPU는 **3번째 합성곱 층과 완전 연결 층에서만** 정보를 주고받습니다.

---

## 1. 🏗️ 네트워크의 기본 구조

| 구성 | 개수 | 비고 |
|---|:---:|---|
| 🟦 **합성곱 층** (Conv) | **5개** | 특징 추출 |
| 🟩 **완전 연결 층** (FC) | **3개** | 분류 |
| 🎯 **출력** | 1000-way **Softmax** | ImageNet 1,000개 클래스 |
| 📦 **매개변수 수** | 약 **6,000만 개** | |
| 🧠 **뉴런 수** | 약 **65만 개** | |

### 🗺️ 전체 흐름

```
 입력 224×224×3
      │
      ▼
 ┌─ GPU 1 ─────────────────────┐   ┌─ GPU 2 ─────────────────────┐
 │ Conv1  11×11, s4  → 48      │   │ Conv1  11×11, s4  → 48      │
 │   + ReLU + LRN + MaxPool    │   │   + ReLU + LRN + MaxPool    │
 │            │                │   │            │                │
 │ Conv2  5×5        → 128     │   │ Conv2  5×5        → 128     │   ← 같은 GPU에서만 입력
 │   + ReLU + LRN + MaxPool    │   │   + ReLU + LRN + MaxPool    │
 └────────────┼────────────────┘   └────────────┼────────────────┘
              ╰──────────── ✅ 교차 ────────────╯
 ┌────────────┼────────────────┐   ┌────────────┼────────────────┐
 │ Conv3  3×3        → 192     │   │ Conv3  3×3        → 192     │   ← 양쪽 GPU 모두에서 입력
 │            │                │   │            │                │
 │ Conv4  3×3        → 192     │   │ Conv4  3×3        → 192     │   ← 같은 GPU에서만 입력
 │            │                │   │            │                │
 │ Conv5  3×3        → 128     │   │ Conv5  3×3        → 128     │   ← 같은 GPU에서만 입력
 │   + ReLU + MaxPool          │   │   + ReLU + MaxPool          │
 └────────────┼────────────────┘   └────────────┼────────────────┘
              ╰──────────── ✅ 교차 ────────────╯
                FC6  4096  (2048 + 2048)  + Dropout      ← 이전 층 전체에서 입력
                FC7  4096  (2048 + 2048)  + Dropout
                FC8  1000  → Softmax
```

---

## 2. 🔀 GPU 분할과 통신 지점

네트워크의 각 층을 **반씩 나눠 GPU 두 대**에 올립니다(3.2절 참고). 두 GPU는 **특정 층에서만** 통신합니다.

| 층 | 입력을 받는 곳 | GPU 간 통신 |
|---|---|:---:|
| Conv2 | 같은 GPU의 Conv1 출력 | ❌ |
| **Conv3** | **양쪽 GPU**의 Conv2 출력 전체 | ✅ |
| Conv4 | 같은 GPU의 Conv3 출력 | ❌ |
| Conv5 | 같은 GPU의 Conv4 출력 | ❌ |
| **FC6 · FC7 · FC8** | 이전 층의 **모든 뉴런** | ✅ |

> 🎯 **목적**: 매 층마다 통신하면 느려집니다. 통신 지점을 줄여 **통신량을 연산량에 비해 감당할 만한 수준**으로 맞춘 것입니다.

---

## 3. 🔬 층별 상세 분석

> 출력 크기는 **GPU 한 대 기준**이고, 괄호 안은 **두 GPU 합계**입니다.

| 층 | 커널 크기 (입력 깊이) | 보폭 | 커널 수 | 출력 크기 (GPU 1대) | 뒤에 붙는 처리 |
|---|---|:---:|:---:|---|---|
| **입력** | – | – | – | 224×224×3 | – |
| **Conv1** | 11×11 (×3) | 4 | **96** | 55×55×48 (×2) | ReLU → LRN → MaxPool |
| **Pool1** | 3×3 | 2 | – | 27×27×48 (×2) | |
| **Conv2** | 5×5 (×48) | 1 | **256** | 27×27×128 (×2) | ReLU → LRN → MaxPool |
| **Pool2** | 3×3 | 2 | – | 13×13×128 (×2) | |
| **Conv3** | 3×3 (×**256**) ✅ | 1 | **384** | 13×13×192 (×2) | ReLU |
| **Conv4** | 3×3 (×192) | 1 | **384** | 13×13×192 (×2) | ReLU |
| **Conv5** | 3×3 (×192) | 1 | **256** | 13×13×128 (×2) | ReLU → MaxPool |
| **Pool5** | 3×3 | 2 | – | 6×6×128 (×2) | |
| **FC6** | – | – | – | 2048 (×2) = **4096** | ReLU → Dropout |
| **FC7** | – | – | – | 2048 (×2) = **4096** | ReLU → Dropout |
| **FC8** | – | – | – | **1000** | Softmax |

### 📌 표에서 볼 점

- **Conv3의 입력 깊이는 256**입니다. 같은 GPU의 128개뿐 아니라 **양쪽 GPU의 Conv2 출력 전체**를 받기 때문입니다. 다른 합성곱 층은 같은 GPU의 절반만 받습니다(Conv2: 48, Conv4·Conv5: 192).
- **Conv3, Conv4, Conv5 사이에는 풀링도 정규화도 없습니다.**
- 풀링은 모두 3.4절의 **오버래핑 최대 풀링**(3×3 창, 보폭 2)입니다.
- **ReLU**는 모든 합성곱 층과 완전 연결 층의 출력에 적용합니다.
- **LRN**은 1번째와 2번째 합성곱 층에만 적용합니다.

> 📐 **224 vs 227 이야기**
> 논문에는 입력이 **224×224**라고 적혀 있습니다. 하지만 $\dfrac{224 - 11}{4} + 1 = 54.25$로 Conv1의 출력 55가 딱 떨어지지 않습니다. 그래서 많은 구현에서는 **227×227**을 쓰거나 테두리에 여백(padding)을 더합니다.
> $\dfrac{227 - 11}{4} + 1 = 55$ ✅

## 4. 🟩 완전 연결 층 (Fully Connected Layers)

마지막 풀링 출력(6×6×256 = **9,216개** 값)을 1차원으로 펼쳐 완전 연결 층에 넣습니다.

| 층 | 뉴런 수 | 역할 |
|---|:---:|---|
| **FC6** | **4096** (GPU당 2048) | 고수준 특징 조합 |
| **FC7** | **4096** (GPU당 2048) | 고수준 특징 조합 |
| **FC8** | **1000** | ImageNet 1,000개 클래스 점수 → **Softmax**로 확률 계산 |

> 📝 논문 그림에 2048로 표시된 것은 **GPU 한 대 몫**입니다. 두 GPU를 합치면 4096개입니다.

### 🎯 학습 목표

정답 클래스의 로그 확률을 최대화합니다. 이를 **다항 로지스틱 회귀**(multinomial logistic regression) 목표라고 하며, 오늘날의 **교차 엔트로피 손실**과 같습니다.

## 5. ⭐ 이 구조의 중요성

이 구조로 AlexNet은 **ILSVRC-2012에서 우승**했습니다. Top-5 오류율은 **15.3%**로, 2위(26.2%)와 큰 차이였습니다. 이 결과가 **딥러닝 혁명**의 출발점이 되었습니다.

| 핵심 기법 | 역할 | 관련 절 |
|---|---|:---:|
| ⚡ **ReLU** | 학습 속도 대폭 향상 | 3.1 |
| 🖥️ **2-GPU 병렬화** | GPU 메모리 한계 극복 | 3.2 |
| ⚔️ **LRN** | 일반화 성능 향상 | 3.3 |
| 🔗 **오버래핑 풀링** | 오류율 감소, 과적합 완화 | 3.4 |
| 🛡️ **데이터 증강** | **입력 이미지**를 변형해 과적합 방지 | 4.1 |
| 🎲 **드롭아웃** | **FC6·FC7**에서 뉴런을 무작위로 꺼서 과적합 방지 | 4.2 |
