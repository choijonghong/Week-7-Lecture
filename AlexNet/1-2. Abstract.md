# AlexNet 논문 해설 — Abstract

> **주제:** 이미지 분류 성능 지표와 AlexNet의 주요 성과  
> **논문:** *ImageNet Classification with Deep Convolutional Neural Networks* (2012)

---

## 1. Top-5 테스트 오류율 (Top-5 Test Error Rate)

### 정의와 의미

- **용도:** 이미지 분류 모델의 성능을 평가하는 지표입니다.
- **정의:** 실제 정답 레이블이 모델이 예측한 **상위 5개 레이블에 포함되지 않는 비율**입니다.
- **해석:** **Top-5 오류율이 낮을수록** 모델의 이미지 분류 성능이 좋습니다.

> **쉽게 이해하기**  
> 사진의 정답이 ‘고양이’일 때, AI가 제시한 다섯 가지 후보 중 ‘고양이’가 있다면 Top-5 기준에서는 정답입니다. 다섯 후보 모두에 없다면 오류로 계산합니다.

---

## 2. Abstract 요약 — 이미지 분류 기술 개요

AlexNet 논문의 초록(Abstract)은 ImageNet 대규모 이미지 인식 과제에서 CNN이 거둔 성과를 소개합니다. 이는 초기 딥러닝 혁명을 이끈 대표적인 사례입니다.

### 2.1 도전 과제 및 모델 구조

| 항목 | 내용 |
|:---|:---|
| **대회·데이터** | ImageNet LSVRC-2010 데이터 활용 |
| **분류 과제** | 약 **120만 장**의 고해상도 이미지를 **1,000개 클래스**로 분류 |
| **모델** | 합성곱 신경망(CNN) |
| **파라미터** | 약 **6,000만 개** |
| **뉴런** | 약 **65만 개** |
| **합성곱 계층** | **5개** |
| **연산 가속** | GPU 활용 |
| **과적합 완화** | 드롭아웃(Dropout) 적용 |

**핵심 기술 설명**

- **CNN:** 이미지에서 가장자리·형태 등 특징을 단계적으로 추출합니다.
- **GPU:** 대규모 행렬 연산을 빠르게 처리해 학습을 돕습니다.
- **Dropout:** 학습 중 일부 뉴런을 무작위로 비활성화해 과적합을 줄입니다.
- **Max-pooling:** 특징 맵의 공간적 크기를 줄이면서 중요한 특징을 유지합니다.

### 2.2 주요 성과

| 평가 대상 | 지표 | 오류율 |
|:---|:---|---:|
| **ILSVRC-2010 데이터** | Top-1 테스트 오류율 | **37.5%** |
| **ILSVRC-2010 데이터** | Top-5 테스트 오류율 | **17.0%** |
| **ILSVRC-2012 대회 AlexNet** | Top-5 테스트 오류율 | **15.3%** |
| **ILSVRC-2012 대회 2위 모델** | Top-5 테스트 오류율 | **26.2%** |

> **성과의 의미**  
> 2012년 대회에서 AlexNet은 2위보다 **10.9%포인트 낮은 Top-5 오류율**을 기록하며 우승했습니다. 이 성과는 이미지 인식 분야에서 딥러닝의 가능성을 널리 알리는 계기가 되었습니다.

---

## 3. 핵심 정리

1. **Top-5 오류율**은 정답이 상위 5개 예측에 없는 비율입니다.
2. AlexNet은 약 **120만 장의 이미지**를 **1,000개 클래스**로 분류하는 과제를 다뤘습니다.
3. 약 **6,000만 개 파라미터**, **65만 개 뉴런**, **5개 합성곱 계층**을 활용했습니다.
4. **GPU**로 연산을 가속하고 **Dropout**으로 과적합을 완화했습니다.
5. 2012년 ILSVRC에서 **Top-5 오류율 15.3%**로 우승했습니다.
