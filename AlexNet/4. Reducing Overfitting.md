# 4. 과적합 줄이기 (Reducing Overfitting)

> **논문**: A. Krizhevsky, I. Sutskever, G. E. Hinton, "ImageNet Classification with Deep Convolutional Neural Networks", *NeurIPS*, 2012. (AlexNet)

> 💡 **한 줄 요약**
> 매개변수가 **6,000만 개**나 되는 AlexNet은 훈련 데이터를 외워 버리기 쉽습니다. 이를 막기 위해 두 가지 기법을 씁니다. **데이터 증강**은 같은 사진을 여러 모양으로 바꿔 보여 주고, **드롭아웃**은 뉴런을 무작위로 꺼서 서로 기대지 못하게 합니다.

---

## 🤔 왜 과적합이 문제인가?

| 항목 | 내용 |
|---|---|
| 매개변수 수 | 약 **6,000만 개** |
| 훈련 이미지 | 약 **120만 장** |
| 정답이 주는 정보 | 1,000개 중 하나이므로 이미지 한 장당 약 **10비트**($\log_2 1000 \approx 10$) |
| 문제 | 정답이 주는 정보에 비해 매개변수가 너무 많아, 이것만으로는 과적합을 막기 어렵습니다. |

> 📚 **과적합이란?** 시험 범위의 문제와 답만 통째로 외운 학생과 같습니다. 연습 문제는 다 맞히지만, **처음 보는 문제**(새 데이터)는 틀립니다.

| 기법 | 핵심 아이디어 | 비유 |
|---|---|---|
| 🖼️ **4.1 데이터 증강** | 데이터를 **변형해서 늘리기** | 같은 고양이를 여러 각도·조명으로 보여 주기 |
| 🎲 **4.2 드롭아웃** | 뉴런을 **무작위로 끄기** | 매번 팀원 절반을 무작위로 쉬게 하기 |

---

## 4.1 🖼️ 데이터 증강 (Data Augmentation)

> **쉽게 이해하기**: 사진을 여러 위치와 조명으로 **다시 찍은 것처럼** 만들어 보여 줍니다.

새 데이터를 모으지 않고, 이미 가진 훈련 이미지를 **정답(레이블)이 바뀌지 않는 범위에서** 변형해 데이터를 늘립니다.

### 💸 계산 비용이 사실상 0

- 변형한 이미지는 **디스크에 저장하지 않고** 그때그때 만듭니다.
- **CPU**가 다음 배치의 이미지를 만드는 동안, **GPU**는 이전 배치로 학습합니다.
- 그래서 저자들은 이 방식을 **"계산적으로 공짜"**(computationally free)라고 표현합니다.

---

### ① 기하학적 변형: 무작위 자르기 + 좌우 반전

```
     256×256 원본                 무작위 위치에서 224×224를 잘라냄
  ┌──────────────────┐          ┌──────────────────┐
  │ ┌──────────────┐ │          │   ┌──────────────┤
  │ │              │ │          │   │              │
  │ │   224×224    │ │   또는   │   │   224×224    │   + 50% 확률로 좌우 반전
  │ │              │ │          │   │              │
  │ └──────────────┘ │          │   │              │
  └──────────────────┘          └───┴──────────────┘
```

- **방법**: 256×256 이미지에서 **224×224 크기 조각**을 무작위 위치에서 잘라내고, 좌우 반전도 함께 씁니다.
- **예시**: 고양이 사진을 보여 줄 때마다 고양이가 **조금 왼쪽, 조금 위쪽**에 있거나 **좌우가 뒤집힌** 모습이 됩니다. 잘라낸 조각이 원본의 대부분(약 77%)이라, 고양이는 거의 항상 사진 안에 남아 있습니다.
- **효과**: 위치가 조금 바뀌거나 좌우가 뒤집혀도 **같은 물체**라는 것을 배웁니다.

#### 🔢 2048배는 어떻게 나왔나?

$$
\underbrace{(256 - 224)^2}_{\text{자르는 위치 } 32 \times 32 = 1024} \times \underbrace{2}_{\text{반전 여부}} = 2048
$$

> ⚠️ 2048배라고 해서 **완전히 새로운 사진이 2048장** 생기는 것은 아닙니다. 서로 매우 비슷한 이미지들입니다. 그래도 이 기법이 없으면 과적합이 심해져 **훨씬 작은 네트워크**를 써야 했습니다.

#### 🧪 테스트할 때는?

한 이미지에서 **10개의 조각**을 잘라 각각 예측하고, Softmax 결과를 **평균**합니다.

| 조각 | 개수 |
|---|:---:|
| 네 모서리 + 가운데 | 5개 |
| 위 5개의 좌우 반전 | 5개 |
| **합계** | **10개** |

### ② 색상·밝기 변형 (PCA Color Augmentation)

- **방법**: 훈련 세트 전체의 RGB 픽셀 값에 **PCA**(주성분 분석)를 적용해, 색이 주로 변하는 **3가지 방향**을 찾습니다. 그 방향을 따라 무작위 크기의 변화를 각 픽셀에 더합니다.

$$
\text{새 픽셀} \;=\; \text{원래 픽셀} \;+\; [\mathbf{p}_1,\ \mathbf{p}_2,\ \mathbf{p}_3]\,[\alpha_1\lambda_1,\ \alpha_2\lambda_2,\ \alpha_3\lambda_3]^{T}
$$

| 기호 | 의미 |
|---|---|
| $\mathbf{p}_i$ | RGB 공분산 행렬의 $i$번째 **고유벡터** (색이 변하는 방향) |
| $\lambda_i$ | $i$번째 **고유값** (그 방향으로 얼마나 많이 변하는지) |
| $\alpha_i$ | 평균 0, 표준편차 0.1인 **무작위 값**. 이미지를 학습에 쓸 때마다 한 번 새로 뽑습니다. |

- **예시**: 같은 고양이 사진이 어떤 때는 **약간 푸른 조명** 아래, 어떤 때는 **따뜻한 햇빛** 아래에 있는 것처럼 보입니다.
- **효과**: 물체의 정체는 **조명의 색과 밝기가 바뀌어도 변하지 않는다**는 성질을 배웁니다. 색에 덜 의존하고 **모양** 같은 본질적인 특징에 더 집중하게 됩니다.
- **결과**: Top-1 오류율이 **1%p 넘게** 감소했습니다.

## 4.2 🎲 드롭아웃 (Dropout)

> **쉽게 이해하기**: 팀 프로젝트에서 **매번 무작위로 절반의 팀원을 쉬게** 합니다.

여러 모델의 예측을 합치면(앙상블) 성능이 좋아지지만, 큰 신경망을 여러 개 훈련하는 것은 너무 비쌉니다. **드롭아웃**(Hinton 외, 2012)은 훈련 비용을 **약 2배**만 들여 비슷한 효과를 냅니다.

### 🏋️ 훈련할 때

- **방법**: 각 뉴런의 출력을 **확률 0.5로 0**으로 만듭니다. 꺼진 뉴런은 순전파에도 역전파에도 참여하지 않습니다.
- **적용 위치**: **FC6, FC7**(처음 두 완전 연결 층)
- **예시**: 뉴런 10명이 함께 예측을 낸다고 해 봅시다. 이번 이미지에는 무작위로 고른 5명만, 다음 이미지에는 또 다른 5명만 일합니다.

```
  훈련 1회차:  ● ○ ● ● ○ ○ ● ○ ● ●      ● 일함   ○ 쉼
  훈련 2회차:  ○ ● ● ○ ● ● ○ ● ○ ●      (매번 새로 무작위 선택)
```

#### ✨ 효과

| 효과 | 설명 |
|---|---|
| 🚫 **공동 적응 방지** (Co-adaptation) | "B가 있어야만 A가 제 역할을 하는" 식으로 특정 뉴런끼리 의존하는 것을 막습니다. |
| 💪 **튼튼한 특징 학습** | 누가 쉴지 모르므로, 각 뉴런은 **여러 동료 조합과 함께 써도 쓸모 있는** 특징을 배웁니다. |
| 🎭 **앙상블 효과** | 입력이 들어올 때마다 **다른 구조의 신경망**을 훈련하는 셈입니다. 이 신경망들은 모두 **가중치를 공유**합니다. |

### 🧪 테스트할 때

- **방법**: 드롭아웃을 끄고 **모든 뉴런을 사용**합니다. 대신 출력에 **0.5를 곱합니다**.
- **이유 ①: 크기 맞추기**. 훈련 때는 평균적으로 절반만 켜져 있었으므로, 다음 층이 받는 입력의 크기를 훈련 때와 비슷하게 맞춥니다.
- **이유 ②: 앙상블 근사**. 뉴런이 $N$개면 가능한 구조는 $2^N$개입니다. 0.5를 곱하는 것은 이 수많은 신경망의 예측을 **평균 내는 것을 근사**한 것입니다. 정확히는 기하 평균에 대한 합리적인 근사입니다.

### ⚖️ 대가

| 장점 | 단점 |
|---|---|
| 과적합을 **크게 줄임** (드롭아웃이 없으면 과적합이 심했음) | 수렴에 필요한 반복 횟수가 **약 2배**로 늘어남 |

## 📝 결론

| 기법 | 무엇을 바꾸나 | 어디에 적용하나 | 효과 |
|---|---|---|---|
| 🖼️ **무작위 자르기·반전** | 입력 이미지의 위치·방향 | **입력** | 훈련 데이터를 사실상 2048배로 늘림 |
| 🎨 **PCA 색상 변형** | 입력 이미지의 색·밝기 | **입력** | Top-1 오류율 1%p 넘게 감소 |
| 🎲 **드롭아웃** | 뉴런의 활성화 | **FC6, FC7** | 과적합을 크게 줄임 (학습 시간은 약 2배) |

$$
\text{데이터 증강 (입력 다양화)} \;+\; \text{드롭아웃 (뉴런 독립성)} \;\Rightarrow\; \text{거대한 모델도 과적합 없이 학습}
$$
